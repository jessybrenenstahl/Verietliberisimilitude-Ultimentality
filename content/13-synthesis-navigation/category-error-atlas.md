# The Category-Error Atlas

Use this guide to locate a mistaken inference, then examine the linked claim. It is not a list of subjects forbidden from bearing on one another.

| Error | Repair | Source |
|---|---|---|
| One possible object treated as a defining ingredient | Separate what a process concerns from what composes it | [[reconciliation]] |
| A distinction treated as statistical independence | Trace the relation; distinct questions may share causes | [[causal-source-and-experiential-format]] |
| A missing record treated as a missing event | Separate unverified history from evidence that the event did not occur | [[scar-record]] |
| A failed challenge treated as proof, or all success denied evidential value | Assess what a discriminating test actually establishes | [[outcomes-of-attack]] |
| An instance dismissed because a claim is abstract | Show the instance's relevance to the claimed function | [[same-level-attack-rule]] |
| A completed correction treated as immunity | Preserve effective revision without requiring endless review | [[correction-without-regress]] |
| An unchanged result treated as inability to change | Distinguish justified retention from a blocked update path | [[dynamic-fixed-point]] |
| A generated description treated as the operation described | Test whether the described constraint actually regulates | [[sculpted-captive]] |
| An alternate formulation treated as proof the original concept does no work | Compare preserved function and explanatory scope | [[term-as-operator]] |
| Missing regulation treated as inevitable pathology | Identify the mechanism producing the failure in the case | [[absolutization]] |
| Inheritance or fidelity treated as compulsory identity | Examine the successor's capacity to assess, revise, or refuse | [[responsible-successor]] |
| Semantic participation treated as consent | Keep significance distinct from authorization | [[refusal-as-participation]] |
| Compactness treated as universal coverage | State reconstruction scope, context, and evidence | [[compression-without-false-closure]] |

The atlas's assignments can be wrong. A successful correction changes the row and the affected formulations; merely naming a category error does not settle the dispute.
