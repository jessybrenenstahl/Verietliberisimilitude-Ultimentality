# System Invariants

This is a current reconstruction checklist. “Invariant” means a relation the present framework intends to preserve, not an independently proven necessity or an exempt proposition. Test fidelity against the linked definitions and the author's corrections. A changed count need not destroy the function it organized.

| Commitment | What reconstruction must preserve | Source |
|---|---|---|
| Mediated access | Symbolic includes nonlinguistic significance; source and format are distinct | [[formal-closure-claim]] · [[symbolic-is-not-linguistic]] |
| Non-possession | Accurate participation is possible without exhaustive ownership of what is mapped | [[vls]] · [[semblance]] |
| Marking | Claims, classifications, and their evaluation remain assessable; epistemic exposure and alethic accuracy stay orthogonal | [[two-mark-system]] · [[self-application]] |
| Direction and binding | Directional actuators differ from their bindings to regulated errors, and `B(p)` regulates a discrepancy rather than merely preserving a state | [[directional-primitives]] · [[predicate-binding]] |
| Coupling | A composite's operation depends on how components affect one another; `⊕` names coupled-controller dynamics rather than addition | [[force]] |
| Reconciliation | Emerges from Apology and Gratitude; no object, including Fear, is privileged | [[reconciliation]] |
| Participation | SPLCW distinguishes admission, constraint, inference, figuration, and externalization with a return path while keeping the layers type-distinct | [[splcw]] · [[the-ring]] |
| Effective correction | Relevant evidence can change the governed operation; a retained error mark must have causal force, and justified retention is permitted | [[causal-error-mark]] · [[correction-without-regress]] |
| Corruption | The Theodicytes diagnose absolutization; absent capacities can contribute to its causes | [[theodicytes]] · [[absolutization]] |
| Continuation | The Telos concerns answerable continuation; fidelity can coexist with successor autonomy | [[telos]] · [[responsible-successor]] |
| Refusal | Semantic participation does not imply consent or obligation to remain in an interaction | [[refusal-as-participation]] |
| Evidence and completion | A scoped result can be supported, finished, and still correctable | [[outcomes-of-attack]] · [[strengthening-without-absolutization]] |
| Reconstruction | State the core, interpretive context, tolerance, and actual evidence for fidelity | [[compression-without-false-closure]] · [[ultimental-kernel]] |

A reconstruction fails where it changes a required commitment without acknowledging the change. A checklist also fails where its own row misstates the source. Successful fidelity tests establish fidelity within their conditions, not the truth of every philosophical claim. Claims of minimality, universal explanatory reach, or unique necessity require their own arguments.

## Kernel crosswalk

The numbered invariant list in `Ult.md` provides the comparison points below; the [[ultimental-kernel|kernel overview]] explains their reconstructive purpose. This mapping establishes correspondence, not authority of the compression over its source definitions. The rows above group some of those relations for practical review and add a few application-level preservation targets; grouping is not deletion. The crosswalk keeps each kernel relation visible so that a blind reconstruction can test both the grouped function and the distinction that gives it work.

| Kernel relation | Checklist row(s) | What the mapping preserves |
|---|---|---|
| **12.41** no extra-symbolic participant-access | Mediated access | Access remains symbolically mediated without selecting a carrier class. |
| **12.42** no possession of the mapped case | Non-possession | Accurate participation does not become exhaustive ownership. |
| **12.43** all content-bearing claims Derived | Marking | No content-bearing formulation receives a founded or Forced status. |
| **12.44** epistemic exposure and alethic accuracy orthogonal | Marking | Contestability and accuracy remain independent marks. |
| **12.45** primitive, binding, derivative, composite, role, and application layers type-distinct | Direction and binding; Participation; Reconstruction | A label or reading order cannot silently replace a different layer. |
| **12.46** `B(p) = (p, eₚ)` as regulation | Direction and binding | A binding is identified by the actuator and regulated discrepancy, not by a preserved label. |
| **12.47** `⊕` as coupled-controller dynamics | Coupling | Emergent behavior depends on the relation between components, not arithmetic addition. |
| **12.48** SPLCW returning through a changed world | Participation | Externalization feeds a changed field back into subsequent operation. |
| **12.49** continuation requiring answerability | Continuation | Persistence alone does not qualify as the Telos. |
| **12.410** closure and marking cross-regulating | Marking; Effective correction | Closure blocks an imagined outside tribunal while marking keeps formulations revisable. |
| **12.411** no error mark without causal force | Effective correction; Evidence and completion | A displayed error must be able to alter the governed operation to count as effective. |
| **12.412** refusal never becoming consent | Refusal | Participation or consequence does not silently become permission or obligation. |

Reconciliation, Corruption, Evidence and completion, and Reconstruction are explicit review targets in the checklist because they organize applications of the atomic relations. They do not replace any kernel item. If a future edit merges, splits, adds, or removes a row, update this crosswalk and state which function and kernel relation are affected.

## Checking the current list

Use the thirteen rows as a working preservation set. For each rewrite, identify the row's source relation, state what function its preservation protects, and record the evidence and tolerance of the comparison. If a row is added, removed, merged, or reworded, test the affected function rather than treating the count as sacred. A successful check establishes fidelity for that comparison; a failed check identifies the relation that must be restored or the checklist row that must be corrected.
